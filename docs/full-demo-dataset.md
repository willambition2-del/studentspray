# دليل مجموعة البيانات التجريبية الشاملة (Full Demo Dataset Guide)

منظومة بيانات تجريبية واقعية ومتكاملة لاختبار كافة وظائف منصة الملتقى القرآني عبر الخادم الخلفي (NestJS)، لوحة التحكم الإدارية (Web Admin)، وتطبيق الجوال الموحد (Flutter Mobile App) لجميع الأدوار الستة.

---

## 🌟 المواصفات العامة لمجموعة البيانات

* **الملتقى التجريبي**: `ملتقى النور القرآني النموذجي`
* **المعرّف الثابت (Slug)**: `full-demo-quran-forum`
* **الفروع**: 3 فروع (`الفرع الرئيسي - صنعاء`، `فرع الروضة القرآني`، `فرع الإتقان والتجويد`)
* **الحلقات القرآنية**: 7 حلقات نموذجية
* **المعلمون**: 7 معلمون معتمدون
* **المشرف الفني**: مشرف تعليمي فني مع خطط ونماذج زيارات ميدانية
* **الطلاب**: 100 طالب (بيانات عربية واقعية، مستويات وخطط وسجلات حضور وتسميع واختبارات)
* **أولياء الأمور**: 70 ولي أمر مرتبطين بالطلاب مع كشوفات المتابعة
* **الأدوار الإدارية**: حساب للمدير العام وحساب للمدير التنفيذي
* **البيانات الأكاديمية والتشغيلية**: عام دراسي، فصول، خطط حفظ، 140 جلسة حضور، سجلات تسميع ومراجعة، 10 اختبارات بنتائج معتمدة، زيارات إشرافية، توصيات، مجموعات محادثة، أنشطة، مسابقات، أوسمة وجوائز، مقالات الرف العام، وطلبات وقرارات إدارية.

---

## 🔒 معايير الأمان والعزل الكامل

1. **عزل كامل للبيانات (Multi-Tenant Isolation)**: جميع البيانات مرتبطة حصرياً بـ `full-demo-quran-forum` ولا تؤثر إطلاقاً على أي ملتقى آخر أو بيانات سابقة.
2. **منع التشغيل في الإنتاج**: ترفض برامج الـ Seed والـ Remove العمل نهائياً عند ضبط `NODE_ENV=production`.
3. **سياسة كلمات المرور**: لا يتم تخزين أي كلمة مرور داخل الكود أو المستودع أو المانفيست؛ بل يتم تمريرها محلياً أثناء التشغيل عبر متغير البيئة `DEMO_SEED_PASSWORD` ويتم تشفيرها باستخدام خوارزمية `Argon2id`.
4. **الحذف الآمن القابل للعكس (100% Reversible)**: يتم الحذف عبر `npm run demo:remove` بترتيب مفاتيح الربط بدقة ذرية تضمن تنظيف كافة السجلات التجريبية دون المساس بأي بيانات أصلية في النظام.

## 🛠️ أوامر التشغيل والتحقق والحذف (Commands Guide)

جميع الأوامر يتم تنفيذها من مجلد `backend`:

### 1. إنشاء وزرع البيانات التجريبية (Seed Demo Dataset)

```powershell
cd backend
$env:DEMO_SEED_PASSWORD="YourSecurePassword123!"
npm run demo:seed
```

### 2. التحقق من اكتمال وصحة البيانات (Verify Demo Dataset)

```powershell
cd backend
$env:DEMO_SEED_PASSWORD="YourSecurePassword123!"
npm run demo:verify
```

### 3. معاينة الحذف دون المساس بالبيانات (Dry Run Removal)

```powershell
cd backend
npm run demo:remove:dry
```

### 4. الحذف النهائي للبيانات التجريبية (Atomic Clean Removal)

```powershell
cd backend
$env:CONFIRM_REMOVE_FULL_DEMO="YES"
npm run demo:remove
```
